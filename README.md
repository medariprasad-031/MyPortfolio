# Personal Portfolio Website – Medari Prasad

## About the Project

This is my personal portfolio website developed to showcase my educational background, technical skills, personal information, and development projects.

The website provides a simple, modern, and responsive interface where recruiters, developers, and visitors can learn more about me and explore my work.

## Features

- **Home Section:** Introduction and profile photograph.
- **Education Section:** Displays my academic qualifications and educational background.
- **About Me:** Personal introduction and professional interests.
- **Skills Section:** Displays my technical skills.
- **Projects Section:** Showcases my development projects.
- **Responsive Navigation:** Navigation menu with a mobile menu toggle.
- **Typing Animation:** Animated developer introduction.
- **Profile Photo:** Displays my profile picture.
- **Footer:** Includes email, LinkedIn, and GitHub links.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Interactive functionality and animations.
- Font Awesome – Icons.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all the required files and the profile image are in the correct locations.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code.
